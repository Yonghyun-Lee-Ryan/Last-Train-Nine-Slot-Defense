## 0. 분석 방법론 (투명성)

Google Play Store에서 **유사 장르 약 200개 타이틀의 공통 패턴**을 기준으로 비교했다.  
개별 앱 200개를 실시간 스크래핑한 목록이 아니라, 아래 클러스터에서 소프트런칭·상위 노출 타이틀이 반복적으로 채택하는 **기능/UX 규범(genre norms)** 을 집계한 것이다.

| 클러스터 | 대표 성격 | 표본 비중(약) |
|----------|-----------|---------------|
| A. Merge Defense / Merge TD | 합성+자동전투, 짧은 세션 | 35% |
| B. Survivor / Horde | 생존·자동 공격·웨이브 | 20% |
| C. Classic / Lane TD | 타워 배치·경로 방어 | 15% |
| D. Auto-battler lite | 배치·시너지·라운드 | 10% |
| E. Roguelite deck/defense | 회차·카드·메타 | 10% |
| F. Theme survival (train/city) | 테마·스토리 스킨 | 10% |

비교 축:

1. **콘텐츠** — 유닛/맵/적/모드/시즌 깊이  
2. **조작·전투 UX** — 터치·정보·속도·실수 복구  
3. **유저 입장** — 온보딩·동기·공정성·신뢰·접근성·수익 체감  

상태 표기:

* **강점** — 이미 차별점 또는 충분  
* **부족** — 장르 평균 대비 얇음  
* **없음** — 장르에서 기대되나 미구현  
* **출시차단** — 스토어/수익/신뢰에 직결

## 1. 한눈에 보는 포지션

| 항목 | 막차 생존 현황 | 장르 상위권 기대치 |
|------|----------------|-------------------|
| 핵심 루프 | 3×3 합성 + 노선 디펜스 + 로그라이트 | 동일 계열 중 **보드 제약·테마**는 강점 |
| 콘텐츠 볼륨 | 승객 8 / 노선 1(10역) / 이벤트 2 / 시너지 3 | 유닛 20–50+, 챕터 다수, 이벤트 풀 넓음 |
| 메타 | 해금·숙련·미션·일일·무한·LiveOps 데이터 | 도감 UI·출석·배틀패스·코스메틱이 기본에 가까움 |
| 조작 | 드래그 합성·HUD·사거리·튜토리얼 | 한손·속도·실수복구·가독성 고도화 |
| 수익/신뢰 | 보상형 광고 설계, SDK·정책 URL 미완 | AdMob·정책·Crashlytics·Remote Config 필수 |
| 소셜 | 로컬/목 랭킹 | 길드·친구·실서버 랭킹 또는 **의도적 비소셜** 명확화 |

**결론:** 코어 판타지(막차·9칸·직업 승객)는 차별점이다.  
**부족한 것은 “재미의 씨앗”이 아니라 “장르 유저가 앱을 유지하게 만드는 콘텐츠 두께·조작 편의·신뢰 인프라”다.**

## 6. “따라하지 말 것” (차별점 보호)

장르 평균을 맹목적으로 채우면 **막차·9칸** 정체성이 희석된다.

* 복잡한 장비 파밍으로 배치 퍼즐을 죽이지 않는다.  
* 에너지로 플레이를 과도하게 막지 않는다(광고 보상형 정체성 유지).  
* 멀티플레이를 1차 로드맵에 넣지 않는다.  
* 합성 보드를 9칸 밖으로 키우지 않는다(차별점).
