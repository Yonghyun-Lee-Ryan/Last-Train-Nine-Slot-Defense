## 1. 제품 목표 (Rev3)

### 1.1 한 줄

> **9칸 막차 디펜스의 차별점은 유지**하고, Google Play 유사 장르 유저가 “또 켠다”고 느끼는 **콘텐츠 두께·조작 편의·신뢰 인프라**를 Soft Launch 수준으로 끌어올린다.

### 1.2 성공 지표 (내부 테스트 → Soft Launch)

| 지표 | 내부 목표 | Soft Launch 목표 |
|------|-----------|------------------|
| D1 리텐션 | ≥ 35% | ≥ 40% |
| 튜토리얼 완료율 | ≥ 70% | ≥ 75% |
| 첫 회차 완료율(일반) | ≥ 40% | ≥ 45% |
| 크래시-프리 세션 | ≥ 99% | ≥ 99.5% |
| 보상형 광고 eCPM 루프 성공 | 동작 100% | Remote 한도 내 불만 리뷰 < 5% |

## 2. 유지할 핵심 차별점 (변경 금지)

1. 3×3(9칸) 전장 제약  
2. 일상 직업 승객 + 합성 성장  
3. 지하철 노선·역 진행  
4. 짧은 로그라이트 회차 + 메타 해금  
5. 주 수익 = 보상형 광고(강요형 인터스티셜 남용 금지)

## 3. Rev3 제품 테마

### Theme A — Trust Ready (출시 신뢰)
실광고·분석·크래시·개인정보 URL·정직한 랭킹 표기.

### Theme B — Week-1 Hook (첫 주 훅)
도감, 출석, 홈 목표 카드, 패배 학습, 결과 연출, Daily Rule.

### Theme C — Deck Depth (덱 깊이)
승객/시너지/이벤트/유물 확장, 합성·스킬 피드백.

### Theme D — Route Fantasy (노선 판타지)
Line 확장, Rest 역, Quick Run, Endless 마일스톤, 보스 연출.

### Theme E — Comfort Control (편한 조작)
속도 프리셋, 판매 확인/Undo, 위협 예고, 홈 IA, 접근성 기초.

## 4. 유저 여정 (개선 후)

```text
설치
→ 개인정보/광고 동의(실정책 URL)
→ 튜토리얼(60–90초, 실패해도 진행)
→ 첫 회차(일반) → 결과(패배 원인/보상 연출)
→ 홈: [오늘의 목표] [도감 신규] [시즌]
→ 출석·미션·일일 규칙 변형
→ 난이도/무한/시즌 이벤트
→ (선택) 광고 보상으로 리롤·부활·2배
```

## 5. 기능 기획 요약

### 5.1 Trust Ready
* AdMob / Firebase Analytics / Crashlytics / Remote Config 실배선  
* `privacyPolicyUrl` 실주소 + Play 데이터 안전 양식  
* Endless/랭킹: 서버 전 Mock UI 제거 또는 “로컬 최고”만 표기  
* 인앱 리뷰 타이밍: 클리어 2회 이후  

### 5.2 홈 & 메타 UX
* 홈 탭: 플레이 / 성장(도감·숙련) / 시즌 / 설정  
* 도감: 승객·적·보스·유물 카드, 미발견 실루엣  
* 7일 출석: 조각/무료소환권, 광고로 추가 수령 가능  
* “다음에 할 일” 카드 1개(미션 or 난이도 or 시즌)

### 5.3 콘텐츠 확장 (1차 Soft Launch 팩)
* 승객 +4 (총 12), 시너지 +5 (총 8), 이벤트 +8 (총 10), 유물 +6  
* Line1 템포에 Rest 1 삽입 또는 Line2(8역) 추가  
* Daily Rule Modifier 6종(금일만 적용)  
* Endless 마일스톤 10단 보상  

### 5.4 조작·피드백
* 전투 속도 1/2/3 + 설정 저장  
* 준비 단계: 판매 확인, 합성 Undo 1회  
* 다음 웨이브 적 아이콘, 보스 예고  
* 합성/스킬 발동 VFX·사운드 강화  
* 결과: 신규 해금 연출, 패배 원인 1줄  

### 5.5 LiveOps 얼굴
* 시즌 패스: Free 트랙 + Ad 트랙(유료 IAP는 Soft Launch 이후 옵션)  
* 서버 시각 인터페이스 + Remote 카탈로그 토글  

### 5.6 Soft Launch 이후(명시적 Backlog)
* IAP 광고제거, 코스메틱 상점, Play Games 클라우드 세이브, EN 로컬라이즈, 경량 소지품 슬롯
