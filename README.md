## 2. 핵심 콘셉트

심야 지하철 막차가 정체불명의 괴물에게 습격받는다.

플레이어는 3×3 좌석에 승객을 배치하고, 같은 등급의 승객을 합쳐 강화하며, 각 역에서 몰려오는 괴물을 막아야 한다.

승객은 직업에 따라 서로 다른 전투 능력을 가진다.

* 직장인은 서류를 던진다.
* 배달기사는 빠른 적을 추적한다.
* 헬스 트레이너는 적을 밀쳐낸다.
* 간호사는 다른 승객을 회복한다.
* 개발자는 자동 터렛을 설치한다.
* 대학원생은 일정 확률로 폭발적인 공격을 한다.

### 한 문장 소개

> 9개의 좌석에 승객을 배치하고 합쳐, 종착역까지 막차를 지켜내는 운빨 디펜스 게임.

### 핵심 차별점

1. 3×3의 매우 작은 전장
2. 누구나 아는 일상적인 직업 캐릭터
3. 합성할 때 직업이 성장하거나 전직되는 재미
4. 짧지만 매번 다른 로그라이트 플레이
5. 지하철 노선과 역을 활용한 명확한 진행 구조
6. 실시간 멀티플레이 없이도 가능한 비동기 경쟁

## 3. 핵심 재미

### 3.1 배치의 재미

각 승객은 공격 방향과 사거리가 다르다.

플레이어는 적의 진입 방향과 승객의 능력을 고려해 9개의 좌석을 배치해야 한다.

예시:

* 앞줄: 근접·방어형 승객
* 중간줄: 지원·광역형 승객
* 뒷줄: 원거리·소환형 승객

### 3.2 합성의 재미

같은 캐릭터와 같은 등급을 합치면 한 단계 높은 등급으로 성장한다.

```text
1성 직장인 + 1성 직장인
→ 2성 대리

2성 대리 + 2성 대리
→ 3성 과장

3성 과장 + 3성 과장
→ 4성 부장
```

합성할수록 공격력이 올라가지만, 9칸이라는 공간이 제한되어 있어 다음 선택이 필요하다.

* 지금 바로 합성할 것인가?
* 여러 유닛을 유지할 것인가?
* 특정 조합 효과를 보존할 것인가?

### 3.3 운과 선택의 재미

승객 소환 결과, 역 보상, 능력 카드, 보스 패턴이 매번 달라진다.

다만 완전한 무작위가 되지 않도록 다음 장치를 사용한다.

* 소환 후보 3명 중 하나 선택
* 일정 횟수마다 특정 직업군 확정
* 연속으로 같은 등급만 등장하지 않는 보정
* 광고 또는 게임 재화로 1회 리롤
* 특정 덱을 지원하는 능력 카드

### 3.4 성장의 재미

한 회차 내부 성장과 회차 외부 영구 성장을 분리한다.

#### 회차 내부 성장

* 승객 소환
* 승객 합성
* 능력 카드
* 객차 버프
* 유물
* 노선 전용 강화

#### 회차 외부 성장

* 승객 해금
* 승객 숙련도
* 노선 해금
* 도감
* 객차 외형
* 시작 보너스
* 계정 레벨

## 4. 기본 게임 루프

```text
게임 시작
→ 시작 승객 선택
→ 첫 번째 역 전투
→ 승객 또는 능력 보상 선택
→ 승객 배치·합성
→ 다음 역 전투
→ 중간 보스
→ 추가 능력 선택
→ 일반 역 반복
→ 종착역 보스
→ 결과 및 보상
→ 영구 성장
→ 다음 회차
```

### 짧은 반복 루프

```text
적 등장
→ 자동 전투
→ 코인 획득
→ 승객 소환
→ 좌석 배치
→ 동일 승객 합성
→ 다음 웨이브
```

### 장기 반복 루프

```text
회차 진행
→ 새로운 승객 발견
→ 승객 숙련도 상승
→ 더 어려운 노선 해금
→ 새로운 조합 실험
→ 도감 및 업적 완성
```

## 6. 전장 구조

### 6.1 3×3 좌석

전장은 9개의 슬롯으로 구성된다.

```text
[1] [2] [3]  ← 앞줄
[4] [5] [6]  ← 중간줄
[7] [8] [9]  ← 뒷줄
```

적은 객차 출입문 또는 통로에서 등장해 객차 핵심 지점으로 이동한다.

### 6.2 권장 전투 표현

세로 화면 상단에 적 이동 구역을 배치하고, 하단에 3×3 승객 좌석을 배치한다.

```text
┌─────────────────┐
│      적 등장      │
│ ↓  ↓  ↓  ↓  ↓  │
│                   │
│    전투 이펙트     │
├─────────────────┤
│ [1] [2] [3]       │
│ [4] [5] [6]       │
│ [7] [8] [9]       │
├─────────────────┤
│ 소환 | 합성 | 준비 │
└─────────────────┘
```

### 6.3 객차 내구도

객차에는 체력이 존재한다.

| 항목      | MVP 기본값 |
| ------- | ------: |
| 최대 내구도  |     100 |
| 일반 적 공격 |       5 |
| 정예 적 공격 |      10 |
| 보스 공격   |   15~25 |
| 0 도달 시  |    게임오버 |

승객이 죽는 구조는 MVP에서 제외하고, 객차 내구도만 감소하게 한다.

이후 정식 버전에서 승객 기절 또는 일시적 무력화를 추가할 수 있다.

## 7. 승객 시스템

### 7.1 승객 기본 속성

| 속성      | 설명                |
| ------- | ----------------- |
| ID      | 승객 고유 식별자         |
| 이름      | 표시 이름             |
| 직업군     | 공격·방어·지원·특수       |
| 등급      | 1~5성              |
| 공격력     | 기본 피해량            |
| 공격속도    | 공격 간격             |
| 사거리     | 공격 가능한 범위         |
| 공격 대상 수 | 단일 또는 다중          |
| 스킬      | 고유 능력             |
| 합성 경로   | 상위 등급 캐릭터         |
| 태그      | 직장인, 의료, 기술, 체력 등 |

### 7.2 MVP 승객 8종

#### 1. 야근 직장인

* 역할: 기본 원거리 공격
* 공격: 서류 던지기
* 특징: 가장 안정적인 기본 딜러
* 스킬: 일정 횟수마다 서류 더미를 던져 추가 피해

#### 2. 배달기사

* 역할: 빠른 적 대응
* 공격: 배달 상자 투척
* 특징: 이동속도가 빠른 적을 우선 공격
* 스킬: 체력이 낮은 적에게 추가 피해

#### 3. 헬스 트레이너

* 역할: 근접 방어
* 공격: 덤벨 휘두르기
* 특징: 적을 뒤로 밀어냄
* 스킬: 일정 확률로 강한 넉백

#### 4. 간호사

* 역할: 지원
* 공격: 약한 원거리 공격
* 특징: 주변 승객 공격속도 증가
* 스킬: 일정 시간마다 객차 내구도 회복

#### 5. 개발자

* 역할: 소환·설치
* 공격: 드론 발사
* 특징: 일정 시간마다 임시 터렛 설치
* 스킬: 터렛이 여러 적을 공격

#### 6. 대학원생

* 역할: 확률형 폭딜
* 공격: 논문 투척
* 특징: 기본 공격은 약하지만 낮은 확률로 큰 피해
* 스킬: 치명타 발생 시 주변 적에게 피해

#### 7. 경찰관

* 역할: 보스·정예 대응
* 공격: 진압봉 또는 전기충격기
* 특징: 정예와 보스에게 추가 피해
* 스킬: 보스 행동을 짧게 중단

#### 8. 고양이

* 역할: 행운·특수
* 공격: 평소에는 낮은 피해
* 특징: 낮은 확률로 매우 큰 치명타
* 스킬: 보상 선택지의 희귀도 확률 상승

## 8. 승객 등급과 합성

### 8.1 등급 체계

| 등급 | 표시 | 합성 조건    |
| -- | -- | -------- |
| 1성 | 일반 | 동일 승객 2개 |
| 2성 | 숙련 | 동일 승객 2개 |
| 3성 | 전문 | 동일 승객 2개 |
| 4성 | 달인 | 동일 승객 2개 |
| 5성 | 전설 | 최고 등급    |

MVP에서는 1~3성까지만 구현한다.

### 8.2 합성 규칙

* 같은 캐릭터
* 같은 별 등급
* 서로 다른 슬롯
* 빈 슬롯이 없어도 합성 가능
* 합성 결과는 드래그 대상 슬롯에 배치
* 합성 과정에서 공격 쿨타임 초기화 여부를 통일

### 8.3 합성 보상

합성 시 다음 효과를 제공한다.

* 공격력 상승
* 공격 범위 증가
* 스킬 강화
* 짧은 화면 연출
* 합성 횟수 업적 누적

### 8.4 합성 밸런스 예시

| 등급 | 공격력 배수 | 공격속도 배수 |
| -- | -----: | ------: |
| 1성 |    1.0 |     1.0 |
| 2성 |    2.2 |    1.05 |
| 3성 |    4.8 |     1.1 |
| 4성 |   10.0 |    1.15 |
| 5성 |   21.0 |     1.2 |

단순히 정확히 2배로 만들면 합성의 이점이 약하므로, 상위 등급에 약간의 추가 효율을 제공한다.

## 9. 소환 시스템

### 9.1 기본 소환

적을 처치하면 코인을 얻는다.

코인을 사용해 승객을 소환한다.

| 항목       |      MVP 기본값 |
| -------- | -----------: |
| 초기 소환 비용 |         10코인 |
| 소환 비용 증가 | 소환할 때마다 +2코인 |
| 후보 수     |           3명 |
| 선택 시간    |        제한 없음 |
| 무료 리롤    |       회차당 1회 |
| 광고 리롤    |       회차당 2회 |

### 9.2 소환 방식

소환 버튼을 누르면 무작위 승객 후보 3명이 등장하고 하나를 선택한다.

장점:

* 완전 무작위보다 전략성이 높다.
* 플레이어가 덱 방향을 결정할 수 있다.
* 리롤 광고가 자연스럽다.
* 소환 결과에 대한 불만을 줄일 수 있다.

### 9.3 빈 좌석이 없을 때

다음 선택지를 제공한다.

* 기존 승객 판매
* 동일 승객 자동 합성
* 새 승객 포기
* 보관 슬롯 사용

MVP에서는 보관 슬롯을 제외하고, 기존 승객 판매 또는 소환 취소만 지원한다.

## 10. 승객 판매

필요하지 않은 승객을 판매해 일부 코인을 회수한다.

| 등급 | 판매 가격 |
| -- | ----: |
| 1성 |   5코인 |
| 2성 |  12코인 |
| 3성 |  28코인 |

판매 가격은 합성에 사용된 총비용보다 낮게 설정한다.

판매 버튼을 잘못 누르는 문제를 방지하기 위해 다음 방식을 사용한다.

* 승객 길게 누르기
* 상세 팝업 표시
* 판매 버튼 선택
* 2성 이상은 확인 팝업 표시

## 11. 능력 카드 시스템

특정 역을 통과하면 능력 카드 3장 중 하나를 선택한다.

### 11.1 카드 종류

#### 승객 강화

* 직장인 공격력 +20%
* 간호사 회복량 +30%
* 경찰관 보스 피해 +25%
* 고양이 치명타 확률 +5%

#### 객차 강화

* 객차 최대 내구도 +20
* 역 종료 시 내구도 5 회복
* 적이 객차에 처음 도달할 때 1회 밀쳐냄

#### 경제 강화

* 적 처치 코인 +15%
* 승객 판매 가격 +20%
* 소환 비용 증가량 -1
* 정예 적 처치 시 무료 소환권 획득

#### 조합 강화

* 앞줄 승객 공격력 +15%
* 같은 직업군 3명 배치 시 공격속도 +10%
* 서로 다른 직업 6종 배치 시 모든 피해 +20%

### 11.2 카드 희귀도

| 희귀도 | 기본 확률 |
| --- | ----: |
| 일반  |   60% |
| 희귀  |   30% |
| 전설  |   10% |

## 13. 적 시스템

### 13.1 적 기본 속성

| 속성    | 설명                 |
| ----- | ------------------ |
| 체력    | 적 생존력              |
| 이동속도  | 객차까지 이동하는 속도       |
| 객차 피해 | 도착 시 내구도 감소량       |
| 방어력   | 피해 감소              |
| 태그    | 일반, 빠름, 방어, 정예, 보스 |
| 특수 능력 | 돌진, 보호막, 분열 등      |

### 13.2 MVP 적 5종

#### 1. 취객 괴물

* 일반 적
* 평균 체력과 속도
* 특별한 능력 없음

#### 2. 막차 질주자

* 빠른 적
* 체력은 낮지만 이동속도가 빠름
* 배달기사가 우선 공격

#### 3. 가방 방패병

* 방어형 적
* 받는 피해 일부 감소
* 느리지만 체력이 높음

#### 4. 분열 승객

* 사망 시 작은 적 두 마리 생성
* 광역 공격 캐릭터의 필요성을 만든다

#### 5. 무임승차 감시자

* 정예 적
* 주변 적 이동속도 증가
* 처치 시 추가 코인 제공

## 14. 보스 시스템

### 14.1 중간 보스: 만취한 부장

* 느리게 이동
* 체력이 높음
* 일정 시간마다 승객 한 명의 공격속도 감소
* 경찰관이 추가 피해를 입힘

### 14.2 최종 보스: 기관사 없는 열차

괴물 자체보다 열차 시스템 이상 현상으로 표현한다.

#### 보스 패턴

1. 정전
   일정 시간 일부 슬롯의 공격 중단

2. 급정거
   승객 위치가 무작위로 변경될 가능성

3. 문 개방
   여러 방향에서 적 등장

4. 폭주
   남은 체력 30% 이하에서 이동속도 증가

MVP에서는 다음 두 패턴만 구현한다.

* 일정 시간 공격속도 감소
* 추가 적 소환

## 16. 이벤트 역

이벤트 역은 텍스트와 선택지 중심으로 구성해 콘텐츠 제작 비용을 낮춘다.

### 예시 1. 수상한 자판기

* 음료 구매: 코인 감소, 객차 내구도 회복
* 기계를 흔든다: 일정 확률로 무료 유물 또는 내구도 감소
* 지나간다: 변화 없음

### 예시 2. 잠든 승객

* 깨운다: 무작위 승객 획득
* 소지품을 확인한다: 코인 획득 또는 패널티
* 모른 척한다: 변화 없음

### 예시 3. 끊어진 전광판

* 직접 수리한다: 개발자가 있으면 능력 카드 획득
* 비상 전원을 연결한다: 코인 소모
* 포기한다: 다음 역에서 적 강화

## 22. 비동기 사회 기능

### 22.1 주간 랭킹

* 남은 객차 내구도

* 특급 객차

### 22.4 다른 플레이어 덱 보기

다음 데이터만 공유한다.

* 최종 배치
* 승객 구성
* 능력 카드
* 유물
* 점수

실시간 플레이 동기화는 하지 않는다.

## 32. 핵심 성공 조건

이 게임의 핵심은 캐릭터 수나 화려한 그래픽이 아니다.

플레이어가 매 순간 다음 고민을 하게 만들어야 한다.

* 이 승객을 합칠 것인가?
* 여러 명을 유지할 것인가?
* 앞줄을 강화할 것인가?
* 다음 보스를 대비할 것인가?
* 소환에 코인을 쓸 것인가?
* 객차를 회복할 것인가?

플레이어가 실패했을 때 다음과 같이 생각하게 만드는 것이 목표다.

> 이번에는 개발자를 앞줄이 아니라 뒤쪽에 배치하고, 경찰관을 먼저 3성으로 만들면 보스를 잡을 수 있을 것 같다.
